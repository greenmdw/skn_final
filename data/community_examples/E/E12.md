주식과 엑셀 작업을 하루 열 시간쯤 하는 사람입니다. 창을 여러 개 띄워 놓고 숫자를 계속 입력하기 때문에 숫자 키패드는 필수이고, 혼자 쓰는 방에서 일하는 만큼 소리는 크게 문제가 되지 않습니다. 이번에 풀배열 리니어 키보드를 두 개 써 보았습니다. Corsair K70 CORE RGB는 두 달, Leopold FC900RBT MX2A는 적축으로 6주를 썼습니다.

| 제품 | 크기 | 무게 | 연결 | 사용 기간 |
|---|---|---|---|---|
| K70 CORE RGB | 448 × 153 × 35.4 mm | 934 g | 유선 USB | 2개월 · 주식·엑셀 |
| FC900RBT MX2A (적축) | 442 × 139.3 × 31.8 mm | 1,100 g | 유선 USB · 블루투스 | 6주 · 주식·엑셀 |

## 숫자 키패드와 키감

K70 CORE RGB와 FC900RBT 모두 풀배열이라 숫자 키패드를 편하게 쓸 수 있었습니다. K70 CORE RGB는 MLX Red 리니어 스위치에 작동 압력이 45g이어서 리니어치고는 묵직하게 눌렸고, 숫자를 연속으로 입력할 때 손끝에 적당한 저항이 느껴졌습니다. FC900RBT의 적축은 같은 리니어이지만 조금 더 가볍게 느껴졌고, 엑셀에서 숫자를 길게 치는 동안 손가락이 덜 피곤했습니다.

전에 쓰던 멤브레인 키보드는 숫자 키가 뭉개지는 느낌이었는데, 두 제품 모두 키가 하나씩 또렷하게 눌렸습니다. 같은 리니어이지만 K70 CORE RGB는 묵직해서 천천히 정확하게 입력하는 날에, FC900RBT는 가볍게 빠르게 입력하는 날에 잘 맞았습니다.

## 볼륨 다이얼과 블루투스

K70 CORE RGB에는 볼륨 다이얼이 있어서 주식 방송이나 뉴스 음성을 틀어 놓고 일할 때 키보드에서 바로 음량을 조절할 수 있었습니다. K70 CORE RGB의 볼륨 다이얼은 작은 편의 기능이지만 하루에도 여러 번 쓰다 보니 만족도가 컸습니다. 반면 FC900RBT에는 볼륨 다이얼이 없어서 음량은 모니터 쪽에서 조절해야 했습니다.

FC900RBT는 블루투스가 되기 때문에 태블릿에도 연결해 숫자를 입력할 수 있었습니다. K70 CORE RGB는 유선뿐이라 PC에서만 쓸 수 있었습니다. 저는 책상 앞에서 대부분 일하기 때문에 블루투스를 자주 쓰지는 않았지만, 태블릿에서 차트를 볼 때 FC900RBT의 블루투스는 요긴했습니다.

## 백라이트와 겉모습

FC900RBT는 백라이트가 없습니다. 밝은 방에서 일하는 저에게는 낮 동안 불편함이 없었지만, 저녁에 조명을 낮추면 키 위의 글자가 잘 보이지 않아서 아쉬웠습니다. K70 CORE RGB는 조명이 있어서 어두운 시간에도 키를 찾기 편했습니다. 조명이 필요 없는 환경이라면 FC900RBT의 백라이트 없음은 문제가 되지 않을 거라는 짐작이 듭니다.

겉모습은 K70 CORE RGB가 화려한 조명 때문에 눈에 띄고, FC900RBT는 조명 없이 담백합니다. 무게는 K70 CORE RGB가 934g, FC900RBT가 1,100g으로 FC900RBT가 더 묵직해서 숫자를 세게 눌러도 키보드가 밀리지 않았습니다. 마감은 두 제품 모두 단단했습니다.

저녁에 장이 끝나고 엑셀로 하루 기록을 정리할 때 두 제품의 차이를 다시 느꼈습니다. K70 CORE RGB로 입력하면 키 위의 글자가 은은하게 보여서 조명을 낮춘 방에서도 키를 찾기 쉬웠고, FC900RBT로 입력하면 손이 자리를 기억하고 있어야 했습니다. 숫자 키패드는 손가락이 위치를 외우기 때문에 FC900RBT도 며칠 지나면 문제가 되지 않았지만, 처음 일주일은 어두운 시간에 숫자를 헷갈렸습니다. 낮 시간만 쓰는 분이라면 FC900RBT의 백라이트 없음은 거의 의식되지 않을 거라고 생각합니다. 결국 K70 CORE RGB는 볼륨 다이얼과 조명이 있는 대신 유선뿐이고, FC900RBT는 선택지가 넓은 대신 조명이 없다는 점에서 서로의 약점을 채워 주는 관계였습니다.

## 정리

숫자 키패드가 있는 리니어를 찾는 분께 두 제품 모두 괜찮습니다. 볼륨 다이얼과 조명이 필요하다면 K70 CORE RGB, 블루투스와 담백함이 중요하다면 FC900RBT를 권합니다. 저는 낮에는 FC900RBT, 저녁에는 K70 CORE RGB를 쓰는 편입니다.
