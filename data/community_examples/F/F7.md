구매 고민하는 사람 많은 것 같아서 공개된 스펙만 한곳에 정리함. 직접 써 본 후기 아니고 스펙 정리임.

| 항목 | 내용 |
|---|---|
| 배열 | 텐키리스 |
| 스위치 | Hall Effect 마그네틱 (OmniPoint 3.0) |
| 래피드 트리거 | 있음 |
| 연결 | 유선 (USB) |
| 무게 | 974g |
| 크기 | 355 × 129 × 42 mm |

## 참고할 점

- 텐키리스라 오른쪽 숫자 키패드 없음. 숫자 입력 많은 사람은 확인 필요.
- 연결은 유선 하나. 무선 필요하면 다른 모델 봐야 함.
- 작동 압력은 공개된 수치를 못 찾아서 안 적음.
