## 8. 이 문서를 다시 만들 때

위키 DB를 **읽기 전용**으로 직접 읽는다. `~/wiki` 는 로컬에서만 열린다.

```bash
cd ~/wiki && python3 - <<'PY'
import sqlite3
con = sqlite3.connect("file:dev.db?mode=ro", uri=True)   # 반드시 mode=ro
con.row_factory = sqlite3.Row
c = con.cursor()
for m in c.execute("""select title,status,durationSec,pageId,length(transcript) tn
                      from Meeting where projectId='proj_skn'
                      order by createdAt desc limit 12"""):
    d = m['durationSec'] or 0
    dens = f"{m['tn']/(d/60):.0f}자/분" if m['tn'] and d else "—"
    print(m['title'], m['status'], dens, m['pageId'])
PY
```

- 문서는 `Page`(본문 `contentText`), 녹음은 `Meeting`, 둘 다 `projectId='proj_skn'`
- **본문의 마지막 한 줄이 원문 전사 전체다.** 요약만 보려면
  `[l for l in text.split('\n') if len(l.encode()) < 3000]`
- **`Page.id` 로 인용할 것.** 제목은 전사 품질에 좌우되고 나중에 손으로 고쳐진다
- **전사 밀도를 먼저 보고 읽을 것.** 300자/분 미만이면 근거로 쓰기 전에 원문 대조.
  **다만 밀도가 높아도 숫자는 깨진다**(§1) — 날짜·금액·모델명은 항상 원문 확인
