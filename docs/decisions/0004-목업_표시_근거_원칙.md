# 0004. 목업의 문구·수치는 현재 데이터가 입증하는 범위에서만 표시한다

- 상태: 현행 화면 적용 기준 (2026-09-19)
- 범위: `truefit.html` 목업을 기존 `frontend/`에 이식할 때의 문구·데이터 계약
- 근거: [0001](0001-정제-후-평점을-판정기-없이-내지-않는다.md), [0003](0003-데모-화면에서-세트-신뢰도·회색축·표시용-리뷰-수를-뺀다.md), `frontend/CLAUDE.md`

목업은 디자인 참고 자료이지 API 응답이나 검증 결과가 아니다. 실제 화면은 현재 API가 반환한 값만 표시하고, 값이 없으면 숫자를 만들지 않는다. 이 원칙은 PC와 유아용품에 똑같이 적용하며, 목업을 이식해도 유아 도메인의 카테고리·조건 대화·추천·확정·리포트 동선은 유지한다.

| 목업/화면의 주장 | 현재 표시 기준 |
| --- | --- |
| “조작 리뷰 판정”, “의심 리뷰 제외”, “클렌징 전후 평점”, “실사용 평점” | 표시하지 않는다. 개별 리뷰 진위 판정기와 검증된 제외 집합이 없다. 합성 `cleaned_rating`도 실사용 화면의 평점으로 내지 않는다. |
| 리뷰 관측 | 해당 상품에 실제로 연결된 관측 데이터가 있을 때만 원본 지표·비교 기준·수집 범위를 함께 설명한다. “짧은 기간에 리뷰가 몰림”은 상품 단위 관측이지 조작 판정이 아니다. |
| 리뷰 수·세트 신뢰도 | API 값이 없으면 숨긴다. 0건, 임의 대시, 해시 기반 표시용 수치로 대신하지 않는다. 현재의 세트 신뢰도는 사용자용 확률/점수로 표시하지 않는다. |
| “성능 향상 28~35%” 등 고정 비율 | 표시하지 않는다. 비교 기기, 워크로드, 측정 출처, 계산식이 마련된 뒤 별도 기능으로 구현한다. 현재 추천 점수·성능 tier를 FPS/성능 향상률로 바꾸지 않는다. |
| 가격 예측·할인 가능성 | 표시하지 않는다. 서버의 현재 가격·통화·관측 시각·합성 여부만 표시한다. 목표 가격 알림은 예측이 아니다. |
| 책상 디지털 트윈 “실제 비율” | 치수와 배치 검증이 연결되기 전에는 실제 치수·설치 가능성을 보증하는 문구를 쓰지 않는다. |
| 견적서/이미지 자동 인식 | 업로드 결과가 생겨도 상품 매칭은 사용자 확인 전까지 미확정으로 둔다. 현재는 별도 API가 없으므로 동작하는 기능처럼 표시하지 않는다. |
| 유아용품 안전·리콜·설명서 | 검증 근거가 없으면 안전/적합 판정을 내리지 않는다. 월령·체중·인증·리콜 등 서버가 확인한 항목과 미확인 항목을 구분한다. |

권장 리뷰 소개 문구: “자료가 있는 상품은 리뷰가 짧은 기간에 몰렸는지 등 확인 가능한 관측값을 보여드립니다. 개별 리뷰의 진위는 판정하거나 제외하지 않습니다.”

화면 이식 시에는 PC·유아 두 도메인에서 빈 데이터, 로딩, API 오류, 영문 전환을 확인한다. 신규 기능은 API 계약과 검증 기준을 먼저 정한 뒤 활성화한다.
