# 추천 엔진 리뷰 적합도 계산 알고리즘

사용자 요구에 맞는 리뷰 속성 점수를 결합해 부품별 리뷰 적합도를 계산하고, 기존 최종 점수의 리뷰 축 입력값을 대체한다. 이 문서는 계산 규칙을 설명하는 설계 문서다.

## 1. 계산 흐름과 입력

```text
상품·속성·사용 조건별 긍정/부정 건수 → 속성 점수 Q
사용자 요구 + 부품 종류 → 적용 속성·사용 조건·속성 중요도 α
조건에 맞는 Q와 α의 가중합 → 리뷰 적합도 R
기존 리뷰 축 입력값을 R로 교체 → 기존 가중합으로 최종 점수 계산
```

사용 가능한 리뷰만 적재되며 중복 리뷰 수집은 수집 단계에서 방지된다고 전제한다. 리뷰 문장의 속성 분석과 집계는 리뷰 수집·갱신 시 미리 수행하고, 추천 요청에서는 해당 집계를 조회해 계산한다.

| 입력 | 의미 |
|---|---|
| 상품·평가 대상 | 실제로 평가받은 상품 또는 부속품 |
| 속성 | 정숙성, 발열 관리, 안정성 등 |
| 사용 조건 | 게임 부하, 낮은 부하 등 평가가 성립하는 상황 |
| P / N / mixed | 해당 상품·속성·조건의 긍정 / 부정 / 혼합 관측 수 |
| k | 속성 점수를 중립값으로 보정하는 강도 |
| 요구 프로필 | 요청과 부품 종류에 따른 적용 속성·조건·중요도 |
| 기존 엔진 계산값 | 실제 축별 가중치, 리뷰 외 축의 점수, 패널티 |

리뷰가 등록된 상품 자체의 관측만 사용한다. CPU 리뷰에서 기본 쿨러의 소음을 평가한 문장은 관측·집계에서 제외하며 다른 상품으로 재연결하지 않는다. 관측의 상품은 document_id로 원문 문서의 product_id를 조회한다.

## 2. 속성 점수 Q 계산

상품·속성·사용 조건별로 전체 유효 관측을 집계한다.

- 같은 리뷰에서 같은 속성·조건을 반복해서 평가해도 한 번만 센다.
- 서로 다른 속성이나 명확히 다른 사용 조건은 별도 관측으로 처리한다.
- 같은 속성·조건에서 긍정과 부정을 분리할 수 없으면 mixed로 센다. mixed는 P/N과 Q 계산에서 제외한다.
- 속성 언급이 없거나 판단할 수 없는 문장은 P/N에 포함하지 않는다.

예를 들어 “웹서핑할 때는 조용하지만 게임 중에는 시끄럽다”는 낮은 부하 정숙성의 긍정 관측과 게임 부하 정숙성의 부정 관측이다. 조건을 나눌 수 있으므로 mixed로 처리하지 않는다.

```text
Q = (P + k × 0.5) / (P + N + k)

P, N: 0 이상의 정수
k: 0보다 큰 유한한 수
```

k는 근거가 적을 때 점수를 중립값 0.5 쪽으로 보정한다. P/N이 유한하면 Q의 범위는 `0 < Q < 1`이다. Q는 요구 충족 확률이 아니라 추천용 속성 평가 지표다.

| P | N | mixed | k | Q | 해석 |
|---:|---:|---:|---:|---:|---|
| 8 | 2 | 0 | 4 | 0.714… | 긍정 우세 |
| 2 | 8 | 0 | 4 | 0.285… | 부정 우세 |
| 5 | 5 | 0 | 4 | 0.5 | 긍정·부정 균형 |
| 0 | 0 | 0 | 4 | 0.5 | 관련 근거 없음 |
| 0 | 0 | 3 | 4 | 0.5 | 혼합 관측만 존재 |

별도 집계 상태를 저장하지 않고 P/N/mixed 건수로 해석한다. `k=4`는 예시이며 운영값은 평가 후 고정한다. 동일 속성·조건의 후보에는 동일한 보정 규칙을 적용한다.

## 3. 요구 프로필로 속성 중요도 α 결정

중요도는 `사용자 요구 × 부품 종류 × 속성` 단위로 정한다.

1. 부품 종류에 맞는 기본 속성과 중요도를 선택한다.
2. 사용 용도를 반영하고, 사용자가 명시한 우선순위와 양보 관계를 우선 적용한다.
3. 관련 없는 속성을 제외하고 적용할 사용 조건을 정한다.
4. 남은 속성의 중요도를 정규화해 합계를 1로 만든다.

```text
속성별 비음수 원점수: b_a
α_a = b_a / Σ b_a    (Σ b_a > 0)

α_a ≥ 0
Σ α_a = 1
```

원점수는 근거와 버전이 있는 수동 프로필로 시작한다. 사용자 선호에 따른 여러 비율을 비교해 선택하며, 리뷰 건수나 언급 빈도로 중요도를 정하지 않는다. 명시적 선호가 없으면 부품별 기본 프로필을 사용한다. 적용 속성이 있는데 원점수 합이 0이면 프로필 설정 오류로 처리한다.

예를 들어 조용한 게임용 GPU를 원하는 요청에는 다음과 같은 프로필을 적용할 수 있다. 수치는 설명용이다.

| 속성 | 사용할 조건 | α |
|---|---|---:|
| 정숙성 | 게임 부하 | 0.60 |
| 발열 관리 | 게임 부하 | 0.25 |
| 안정성 | 게임 부하 | 0.15 |

같은 요청의 같은 부품 후보에는 동일한 프로필을 사용한다. 게임 부하의 리뷰가 없다고 낮은 부하의 평가로 대신하지 않는다. 일반 조건과 세부 조건에 같은 관측을 중복 반영하지 않는다.

## 4. 상품별 리뷰 적합도 R 계산

```text
R_i = Σ_a (α_a × Q_i,a)

i: 후보 상품
a: 요구 프로필에서 선택한 속성
Q_i,a: 프로필이 지정한 사용 조건의 속성 점수
```

관련 근거가 없는 속성은 `Q=0.5`를 사용한다. 특정 후보에 자료가 없더라도 α를 바꾸거나, 자료가 있는 속성끼리 다시 정규화하지 않는다. 적용할 속성이 전혀 없으면 `R=0.5`다.

예를 들어 정숙성 자료가 없는 후보의 나머지 Q가 각각 0.7, 0.9라면 다음과 같이 계산한다.

```text
R = 0.60 × 0.5 + 0.25 × 0.7 + 0.15 × 0.9 = 0.610
```

정상 입력에서 R도 `0 < R < 1`이다. 동일한 상품·속성·조건·분석 버전의 Q는 사용자에 따라 바뀌지 않지만, 선택한 조건과 α가 달라지면 R은 달라질 수 있다.

## 5. 최종 점수의 리뷰 축에 반영

기존 엔진이 해당 요청에 대해 계산한 축별 가중치를 그대로 사용한다. 리뷰 축의 입력값만 R로 교체한다.

```text
S_old = Σ_(j ≠ review) (w_j × x_j) + w_review × x_review_old − penalty
S_new = Σ_(j ≠ review) (w_j × x_j) + w_review × R            − penalty

반올림 전 점수 차이:
S_new − S_old = w_review × (R − x_review_old)
```

기존 기본 가중치는 가격 0.35, 성능 0.25, 밸런스 0.15, 리뷰 0.20, 호환 여유 0.05, 소음 0.00이다. 기존 요청별 조정 규칙이 적용된 경우에는 그 결과를 사용한다. 리뷰 가중치를 모든 요청에서 0.20으로 고정하지 않는다.

다른 축의 점수, 패널티, 반올림 및 동점 처리 규칙은 유지한다. 기존 리뷰 행동 지표는 새 R에 섞지 않는다. 리뷰 정숙성은 리뷰 축 내부에서만 반영하며, 기존 소음 축에 추가 입력하지 않는다.

리뷰 점수는 후보를 상위 N개로 줄이기 전에 반영한다. 이후 조합 탐색과 예산·필수 스펙·호환성 검증은 기존 절차를 따른다.

## 6. 전체 계산 예시

조용한 게임용 GPU 후보 A와 B를 비교한다. 모든 관측은 게임 부하 조건이며, k=4와 앞의 중요도를 사용한다. mixed는 모두 0이라고 가정한다.

| 후보 | 속성 | P | N | Q | α | α × Q |
|---|---|---:|---:|---:|---:|---:|
| A | 정숙성 | 14 | 2 | 0.80 | 0.60 | 0.480 |
| A | 발열 관리 | 12 | 4 | 0.70 | 0.25 | 0.175 |
| A | 안정성 | 16 | 0 | 0.90 | 0.15 | 0.135 |
| B | 정숙성 | 4 | 12 | 0.30 | 0.60 | 0.180 |
| B | 발열 관리 | 16 | 0 | 0.90 | 0.25 | 0.225 |
| B | 안정성 | 16 | 0 | 0.90 | 0.15 | 0.135 |

```text
A의 정숙성 Q = (14 + 4 × 0.5) / (14 + 2 + 4) = 0.80

R_A = 0.480 + 0.175 + 0.135 = 0.790
R_B = 0.180 + 0.225 + 0.135 = 0.540
```

리뷰 외 가중합이 A는 0.48, B는 0.51이고, 실제 리뷰 가중치는 0.20, 패널티는 모두 0이면 다음과 같다.

| 후보 | 리뷰 외 가중합 | 리뷰 기여도 | 최종 점수 |
|---|---:|---:|---:|
| A | 0.48 | 0.20 × 0.790 = 0.158 | 0.638 |
| B | 0.51 | 0.20 × 0.540 = 0.108 | 0.618 |

A는 리뷰 외 점수가 낮지만 정숙성을 중요하게 보는 요구에서 리뷰 적합도가 높아 최종 점수가 앞선다. 최종 구성에 포함되는지는 이후 예산과 호환성 및 조합 탐색 결과에 따라 결정된다.

## 7. 계산 시 지킬 예외 처리

- 분석·조회 실패 또는 잘못된 분석 버전은 실행 로그에 기록하고, 영향을 받는 속성 계산에 중립값을 사용한다. 프로필 자체가 잘못되어 결합할 수 없으면 R을 중립값으로 처리하고 설정 오류를 기록한다. 실패를 P/N/mixed가 모두 0인 정상 집계로 저장하지 않는다.
- 음수 건수, 정수가 아닌 건수, k≤0, NaN·무한대, 음수 중요도 등 잘못된 입력은 정상 계산에서 제외하고 오류 처리한다.
- 한 추천 실행에서는 동일한 집계·프로필 버전을 사용한다. 계산 도중 버전이 섞이지 않게 한다.
- 중간 Q와 R을 표시용으로 반올림하지 않는다. 최종 점수는 기존 엔진의 반올림 규칙을 적용한다.
- Q는 전체 유효 관측으로 계산한다. 벡터 검색 유사도와 검색 상위 일부 리뷰는 점수 계산에 사용하지 않는다.
