거래 한 건이 지나가는 길

구매 요청 한 건이 들어오면 아래 순서로 흘러갑니다. 파란 칸이 사람이 개입하는 유일한 지점입니다.

L0 · RFQ구매 요청품목·수량·사양·납기·예산 5필드
L3 · 스크리닝조건 필터재고·사양·납기 미달은 라운드 진입 전 제외
L2 · 협상OFFER ↔ REJECT셀러별 최대 3라운드
L3 · 낙찰최저가 채택SETTLED / NO_DEAL / NO_MATCH
H-02 · 사람최종 승인실제 액션은 무조건 사람
L4 · 리포트요약 + 원문 로그로그에서만 파생

설계 원칙 하나. 리포트는 에이전트가 직접 쓰지 않습니다. 항상 append된 로그를 다시 읽어서만 만들어집니다 — 그래야 리포트와 로그가 어긋날 수 없습니다.

지난주 대비델타 3건

이번 주에 바뀐 것

  • 01

    P0의 정의가 뒤집혔다

    직전 확정안(rev.1)은 “P0에 LLM 1곳(조건 해석)”이었습니다. 회의록 3건을 다시 읽고 LLM 0곳 · 전 구간 룰 기반으로 확정했습니다. 이번 주 가장 큰 방향 전환입니다.

  • 02

    파이프라인이 끝까지 붙었다

    등록 → 매칭 → 협상 → 승인 → 리포트가 한 번에 돌아갑니다. 화면 3장과 API 7개가 1:1로 연결됐고, SQLite라 서버를 재시작해도 데이터가 남습니다.

  • 03

    실패가 두 종류로 갈라졌다

    NO_MATCH(조건 맞는 셀러 자체가 없음)와 NO_DEAL(협상은 했으나 가격 결렬). 사람이 고쳐야 할 것이 다르기 때문에 화면과 로그에서 분리했습니다.

포맷매주 동일

결정은 다섯 칸으로만 적습니다

발표 자료를 나중에 회고 자료로 쓰려면 “무엇을 했는가”가 아니라 “왜 그렇게 정했는가”가 남아야 합니다. 그래서 모든 결정을 아래 다섯 칸에 고정해 적고, 기획 주차든 개발 주차든 칸을 바꾸지 않습니다.

01 쟁점

무엇을 놓고 갈렸는지. 결론이 아니라 질문을 적습니다.

02 선택

실제로 정한 것. 한 문장으로 끝냅니다.

03 버린 대안

이게 없으면 몇 주 뒤 “왜 저 쉬운 길을 안 갔지”가 반복됩니다.

04 근거

회의록 발언과 타임스탬프까지. 기억이 아니라 기록으로 남깁니다.

05 뒤집힐 조건

어떤 사실이 나타나면 이 결정을 되돌리는지. 덕분에 사후에 판단을 채점할 수 있습니다.

이번 주 결정은 7건. 큰 것 두 개를 먼저 보여드리고, 나머지는 묶어서 지나가겠습니다.

LLM 플랫폼인데, MVP엔 LLM을 한 줄도 안 넣기로 했습니다

쟁점

버린 대안

남은 리스크
9/15 데모에서 LLM이 한 번도 안 돌면, 기술 심사위원 앞에서 “왜 에이전트인가”에 답할 근거가 화면에 없습니다. 대응은 위 “뒤집힐 조건”을 발동하거나, 도식에서 구현분과 계획분을 색으로 구분해 단계로 설명하는 것 — 둘 중 하나를 9/5에 고릅니다.
D-3신뢰성

할루시네이션을 LLM이 아니라 룰로 막았습니다

회의에서 나온 실제 사례 — “재고가 10대인데 100대 가능하다고 응답한다.” 검증까지 LLM에게 맡기면 검증자도 같이 틀립니다. 그래서 2단으로 나눴습니다.

1단 — 사전 스크리닝

거짓말할 기회를 주지 않는다

협상 라운드에 들어가기 전에 재고·사양·납기를 룰로 검사합니다. 미달 셀러는 라운드에 진입조차 못 하고, 떨어진 사유가 즉시 로그에 남습니다.

2단 — 감사자

틀렸을 때만 개입한다

LLM 출력을 floor_price·cap_price와 대조해 규칙을 어겼을 때만 보정하고 audit_note를 남깁니다. 정상 출력에는 손대지 않습니다.

부수 효과가 더 좋았습니다. 감사자가 매 턴 도는 게 아니라 위반 시에만 돌기 때문에, 로그에 audit_note가 찍혀 있다는 사실 자체가 “LLM이 틀렸던 지점”의 증거가 됩니다. 나중에 LLM 모드로 전환해도 신뢰성 근거를 그대로 화면에 보여줄 수 있습니다.

선택 — 3곳, 그중 1곳은 조건 미달로 탈락하는 흐름을 일부러 넣습니다.

D-5 AWS는 EC2 1대 + Compose

선택 — 4프로세스만 올립니다. VPC 3개·게이트웨이는 도식에 남기고 구현분과 색을 구분합니다.

근거 — 멘토가 지적한 프록시·VPN 구성을 팀 전체가 아직 이해하지 못한 상태(11시[7:38]) → 데모 범위 밖이 안전

D-6 환경변수는 .env로 통일

선택 — 셸 명령 대신 파일. .env.example만 커밋합니다.

근거 — 팀 OS가 섞여 있어 export가 PowerShell에서 안 먹힙니다. 문서로 설명하는 것보다 문제 자체를 없애는 편이 쌉니다.
