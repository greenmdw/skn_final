# 리뷰 평점 적재·표시 — 동작 설명

수집처(다나와 등)에서 구매자가 매긴 **별점(1~5)** 을 리뷰 원문과 함께 DB에 넣고, 추천 결과·대안 후보·리포트·리뷰 요약·받은 견적 교체 비교에 **평균 별점과 그 별점 건수**를 보여 준다. 이 문서는 현재 코드가 어떻게 동작하는지 설명한다.

> 화면에 나오는 값은 **수집처 구매자 별점의 단순 평균**이다. 조작 리뷰를 걸러 낸 "검수 후 평점"이 아니며, 별점은 추천 순위 계산에 쓰지 않는다(표시 전용).

## 1. 데이터 흐름

```text
data/reviews/*_review_processed.jsonl  (원본 리뷰, record.rating)
  │ db/build_review_seed_bundle.py  ─ source_rating()으로 검사·변환
  ▼
data/review_seed/documents.json        (문서마다 "rating" 키)
  │ db/seed_review_corpus.py --load-bundle --apply  (setup_all.py 5단계)
  ▼
evidence.review_document.rating        (NULL 또는 1~5)
  │ review_service.db_review_stats() / _catalog_review_facts()  ─ 합성 리뷰 제외, 건수·평균 계산
  ▼
API 응답의 review.rating_raw · rating_count
  │ web/src/api/http/mapping.ts  ─ ratingText(), ratingCountOf()
  ▼
화면: "★ 4.7" 또는 "★ 4.7 (별점 120건)"
```

## 2. 저장 (`evidence.review_document.rating`)

`db/migrations/0021_review_document_rating.sql`

```sql
ALTER TABLE evidence.review_document
    ADD COLUMN rating smallint,
    ADD CONSTRAINT review_document_rating_check CHECK (rating IS NULL OR rating BETWEEN 1 AND 5);
```

- 기본값은 없다. 별점이 없는 리뷰는 NULL(모름)이다.
- 리뷰 본문이 바뀔 때 임베딩을 지우는 트리거(`0012`)는 `UPDATE OF body`에만 걸려 있어, 별점만 채우는 갱신은 임베딩을 지우지 않는다.

**값 변환 (`src/services/review_preparation.py`의 `source_rating`)**

| 원본 값 | 저장 값 |
|---|---|
| 1~5 정수 | 그대로 |
| 없음(null) | NULL |
| 0 | NULL — 수집처가 "별점 없음"을 0으로 적은 경우(스피커 리뷰 1건, G마켓 앱 리뷰) |
| 그 밖(소수·문자·범위 밖·참/거짓) | 오류로 중단 |

**현재 적재 결과** (리뷰 문서 5,653건)

| 별점 | 1 | 2 | 3 | 4 | 5 | 없음 |
|---|---:|---:|---:|---:|---:|---:|
| 건수 | 168 | 72 | 165 | 615 | 4,551 | 82 |

별점이 있는 리뷰는 5,571건이고 전체 평균은 4.67이다.

## 3. 적재 (`db/seed_review_corpus.py`)

- 번들의 문서에 `rating` 키가 하나라도 없으면 "번들이 옛 버전입니다"로 중단한다. 옛 번들은 파일 해시가 자체적으로 맞아 해시 검사만으로는 걸러지지 않기 때문이다. 이때는 새 번들을 받는다.
- 모든 문서의 별점을 적재 전에 `source_rating`으로 먼저 검사한다.
- 새 문서는 별점과 함께 넣는다. 이미 있는 문서는 **별점이 NULL일 때만** 채운다(본문은 건드리지 않음). 그래서 별점 컬럼이 생기기 전에 적재한 DB에 같은 번들을 다시 적용하면 별점만 채워진다.
- 넣은 뒤 DB 행을 다시 읽어 번들과 한 칸이라도 다르면 중단한다.

## 4. 집계 — 평균과 건수

두 함수가 같은 규칙으로 계산한다(`src/services/review_service.py`).

| 함수 | 쓰는 곳 | 계산 |
|---|---|---|
| `db_review_stats(conn, product_ids)` | 추천 결과 부품 카드, 대안 후보 목록 — 상품 여러 개를 쿼리 한 번으로 | 상품별 `count`(전체 리뷰 수), `rating_count`, `rating_avg` |
| `_catalog_review_facts(product_key)` | 리뷰 요약(`get_summary`), 리뷰 배지(`review_brief`) | 같은 값 + 관점별 좋다·아쉽다 리뷰 수 |

규칙:
- 별점 건수·평균은 **합성 리뷰(`is_synthetic`)를 뺀** 리뷰로만 센다. 전체 리뷰 수(`count`)는 합성 포함 전체 문서 수다.
- 별점이 NULL인 리뷰는 평균·건수에서 빠진다(SQL `count(rating)`, `avg(rating)`).
- 건수가 적어도 평균을 낸다. 대신 항상 건수를 함께 낸다.
- 평균은 소수 둘째 자리로 반올림한다. 별점이 하나도 없으면 평균은 null이다.

## 5. API에 나가는 값

리뷰 정보는 각 응답의 `review` 객체에 담긴다.

| 필드 | 뜻 |
|---|---|
| `total_count` | 수집한 리뷰 수 |
| `rating_raw` | 수집처 별점 평균(합성 제외). 없으면 null |
| `rating_count` | 그 평균을 낸 별점 건수. 별점이 없으면 null |
| `rating_refined`, `excluded_ratio` | 검수 후 평점·제외 비율 — 리뷰 진위 판정기가 없어 항상 null |

| 화면 / API | 값을 채우는 곳 |
|---|---|
| 추천 결과 부품 카드 (`GET /session/{list_id}/result`) | `review_brief` 결과에 평점이 비어 있으면 `db_review_stats` 값으로 채운다(`_review_with_db_stats`) |
| 대안 후보 목록 (`GET /session/{list_id}/items/{item_id}/alternatives`) | `db_review_stats` 한 번의 결과로 만든다(`_alternative_review`) |
| 리포트 (`GET /lists/{list_id}/report`) | 확정 시점 결과의 같은 `review` 객체 |
| 리뷰 요약 패널 (`GET /reviews/summary/{product_key}`) | `get_summary` — `rating_raw`, `rating_count`와 안내 문장 |
| 받은 견적 교체 비교 (`quote_alternatives`) | `review_brief`의 `rating_raw`, `rating_count` |

리뷰 요약의 안내 문장(`data_notice`)은 별점 건수에 따라 바뀐다.

| 경우 | 문장 끝부분 |
|---|---|
| 모든 리뷰에 별점이 있음 | "평점은 구매자 별점의 단순 평균이고, 리뷰 진위는 따로 판단하지 않았어요." |
| 일부만 별점이 있음 | "평점은 별점이 있는 리뷰 N건의 단순 평균이고, 리뷰 진위는 따로 판단하지 않았어요." |
| 별점이 없음 | "이 제품은 구매자 별점을 수집하지 못했고, 리뷰 진위는 따로 판단하지 않았어요." |

## 6. 화면 표시 (`web/`)

`web/src/api/http/mapping.ts`가 응답을 화면 값으로 바꾼다.

- `ratingText()`: `rating_count`가 없으면 `-`. 별점 건수가 리뷰 수와 같으면 `4.7`, 다르면 `4.7 (별점 120건)`(소수 첫째 자리).
- `reviewsText()`: 리뷰 수가 없으면 `없음`(0건으로 바꾸지 않음).

| 화면 | 표시 |
|---|---|
| 추천 결과·리포트 부품 카드 (`PlanPage.tsx`) | `★ 4.7` + `리뷰 N건` — 별점이 없으면 별점 줄을 숨김 |
| 대안 후보 목록 (`AlternativesDialog.tsx`) | `★ 4.7 · 리뷰 N건` — 별점이 없으면 숨김 |
| 리뷰 요약 패널 (`ReviewSummaryPanel.tsx`) | "평균 별점 ★ 4.67", 별점 건수가 리뷰 수와 다르면 "· 별점 N건"을 덧붙임 |

평균만 따로 보여 주지 않고 항상 건수와 함께 보여 준다. 서버에 없는 값은 0이나 대신할 값으로 채우지 않고 숨긴다.

## 7. 하지 않는 것

- 별점을 추천 점수·순위에 쓰지 않는다. 리뷰가 순위에 반영되는 경로는 리뷰 관점 집계(`review_aspect_aggregate`)뿐이다.
- 조작 리뷰를 걸러 낸 평점(`rating_refined`)은 만들지 않는다.
