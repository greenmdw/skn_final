# 운영비 산출

README [11. 운영비](../../README.md#11-운영비)의 계산 근거입니다. 2026-10-21 기준 단가로 계산했습니다.

## 1. 산출 방법

1. **인프라**: 지금 배포 구성(`docker-compose.aws.yml`, `deploy/aws.env.example`)인 EC2 `t3.medium` 1대 + RDS `db.t3.small` 1대를 서울 리전 온디맨드 단가로 계산합니다. 사용량과 관계없이 매달 고정으로 나갑니다.
2. **AI 호출**: 코드에서 모델을 부르는 곳(`src/agent/`, `src/clients/`, `src/engine/`, `src/workers/`)을 모두 찾아, 기능 1회당 모델 호출 수와 토큰 수를 추정합니다.
   - 시스템 프롬프트·도구 정의·출력 스키마는 실제 코드의 프롬프트 빌더를 호출해 크기를 쟀습니다(모델은 호출하지 않음).
   - 사용자 입력·대화 이력·도구 결과처럼 매번 달라지는 부분과 호출 횟수는 가정입니다.
3. **사용량 시나리오**: 기능 1회 비용을 "세션" 단위로 묶고, 월 세션 수를 소규모·중규모·대규모로 가정해 곱합니다.

실제 토큰 사용량을 기록한 데이터는 아직 없습니다(`llm_client`가 응답의 usage를 저장하지 않음). 운영을 시작하면 실제 사용량으로 이 문서를 갱신해야 합니다.

## 4. AI 호출 — 기능 1회 비용

| 기능 1회 | 모델 호출 | 입력 토큰 | 출력 토큰 | 비용 |
|---|---|---:|---:|---:|
| 조건 대화 1턴 | Strands 에이전트 2회 (도구 호출 + 답). 1회당 시스템 1,580 + 도구 정의 840 + 이력·도구 결과 ~480 | 5,800 | 300 | $0.00073 (1.0원) |
| 추천 실행 1회 | [5] 설명 1회(시스템 718 + 스키마 236 + 구성 ~500, 재생성 20% 가정) + [3-C] 쟁점 문장 2건 | 2,460 | 1,000 | $0.00075 (1.1원) |
| 결과 대화 1턴 | Strands 에이전트 3회 (후보 조회 → 교체 → 답). 1회당 시스템 2,912 + 도구 정의 2,568 + 이력 ~520 | 18,000 | 400 | $0.00200 (2.8원) |
| 견적서 사진 1장 | Vision 1회(시스템 898 + 이미지 ~1,500, 흐린 줄 다시 읽기 30% 가정) | 3,120 | 1,040 | $0.00083 (1.2원) |
| 실시간 스펙 검색 1회 | 웹 검색 1회(검색 내용 ~8,000) + 검증 호출 1회 | 10,000 | 800 | $0.01140 (16.0원) |
| 견적 점검 대화 1턴 | Strands 에이전트 2회. 1회당 시스템 641 + 도구 정의 1,073 + 점검 결과·이력 ~2,300 | 8,000 | 400 | $0.00100 (1.4원) |
| 주변기기 문장 해석 1턴 | 구조화 출력 1회(시스템 1,799 + 출력 스키마 1,707) | 3,550 | 300 | $0.00051 (0.7원) |
| 사용기 분석 1편 | 구조화 출력 1회(시스템 ~2,000 + 본문 평균 1,376자) + 체감 문장 임베딩 | 3,000 | 1,200 | $0.00091 (1.3원) |

- 토큰 수는 한글 1자 ≈ 0.75토큰, 그 밖의 문자 3.6자 ≈ 1토큰으로 어림했습니다. 실제와 ±30% 정도 차이가 날 수 있습니다.
- 이미지 토큰 수는 모델별 이미지 과금 방식을 확인하지 못해 1장당 1,500토큰으로 가정했습니다.
- **가장 비싼 단위는 실시간 스펙 검색**입니다. 비용 대부분이 웹 검색 호출 요금($0.01)이고, 같은 부품은 임시 저장소에 저장돼 다시 검색하지 않습니다. 분당 호출 한도(`LIVE_PART_LOOKUP_LIMIT_PER_MIN`)도 있습니다.
- 에이전트는 매 호출마다 같은 시스템 프롬프트·도구 정의를 보냅니다. OpenAI 프롬프트 캐시가 적용되면 이 부분은 입력 단가의 1/10이 되므로, 위 비용은 **캐시를 고려하지 않은 상한**에 가깝습니다.
- 리뷰 임베딩 백필(5,653건)은 한 번만 하며 약 $0.02로 무시할 수준입니다.

## 7. 다시 계산하는 법

`llm_client`가 응답의 `usage`(입력·출력·캐시 토큰)를 기능별로 기록하게 한 뒤, 한 달 기록으로 4장의 토큰 수와 5장의 세션 구성을 실제 값으로 바꿉니다. 단가는 OpenAI·AWS 공식 가격 페이지에서 다시 확인합니다.
