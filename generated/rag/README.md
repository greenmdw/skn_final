## 확인한 동작

- 월령 질의: **6개월 이상 + 22kg 이하 + 혼자 앉기 + 모든 조건 충족**이 함께 반환된다.
- 바구니 하중: **3kg**이 있는 사양 절과 원문 위치가 반환된다.
- 자립 기능: **지원하지 않음**을 그대로 보존한다.
- 접기 순서·세탁·소독·조립·인증번호: 설명서에 근거가 없으므로 답하지 않는다.
- 다른 상품·옵션·시장·도메인: 대상 자료를 반환하지 않는다.
- 검수된 가상 좌석 조건: 6개월·22kg 경계 포함, 체중 초과·혼자 앉기 미충족 제외.
  조건 입력 누락·근거 상충·미검수는 unknown이며, 부분 문서의 전체 안전성을 통과로 판정하지 않는다.
- 공개/사용 권한 변경, 철회, 버전 교체, 원문 해시 변조, 임베딩·SQL 실패를 검사했다.
- 사실 원장과 정답 파일은 검색 코퍼스에 들어가지 않는다.
